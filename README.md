🛒 Mercearia Proz
📌 Sobre o projeto

O Mercearia Proz é um projeto desenvolvido como atividade prática do curso Proz, com o objetivo de criar um sistema simples de mercearia, permitindo a visualização de produtos em um catálogo e o gerenciamento de produtos por meio de um painel administrativo.

🌐 Acesse o projeto

Site publicado: https://isabellevrabelo.github.io/MerceariaProz/

🚀 Funcionalidades
🏪 Catálogo de produtos
Visualização dos produtos cadastrados.
Pesquisa de produtos pelo nome.
Exibição dos produtos disponíveis.
Acesso à área administrativa.
🔐 Painel do administrador
Cadastro de novos produtos.
Inserção do nome, preço e categoria.
Visualização dos produtos cadastrados em uma tabela.
Pesquisa de produtos.
Gerenciamento dos produtos.
Limpeza do formulário de cadastro.

▶️ Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta no Visual Studio Code.
Localize o arquivo index.html.
Abra no navegador, preferencialmente utilizando a extensão Live Server.
Para acessar o painel administrativo, clique em Administrador.
